This module allows the modification of the invoicing address in the
Shopinvader module.

If there is no invoicing address defined for the customer, the contact
address is returned as default. If there is several invoicing addresses,
the last created one is returned.

When modifying the invoicing address, if there is no invoicing address
defined for the customer or if the invoicing address is used in sales
orders, a new invoicing address is created.
